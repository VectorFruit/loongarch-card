==== LA32R Registers

.LA32R General Purpose Registers
[cols="1,1,2", options="header"]
|===
| Register | ABI Name | Description
| r0       | zero     | Constant zero
| r1       | ra       | Return address
| r2       | tp       | Thread pointer
| r3       | sp       | Stack pointer
| r4       | a0       | Argument/return value
| r5       | a1       | Argument/return value
| r6       | a2       | Argument register
| r7       | a3       | Argument register
| r8       | a4       | Argument register
| r9       | a5       | Argument register
| r10      | a6       | Argument register
| r11      | a7       | Argument register
| r12      | t0       | Temporary register
| r13      | t1       | Temporary register
| r14      | t2       | Temporary register
| r15      | t3       | Temporary register
| r16      | t4       | Temporary register
| r17      | t5       | Temporary register
| r18      | t6       | Temporary register
| r19      | t7       | Temporary register
| r20      | t8       | Temporary register
| r21      | -        | Reserved
| r22      | fp/s9    | Frame pointer/Static register
| r23      | s0       | Static register
| r24      | s1       | Static register
| r25      | s2       | Static register
| r26      | s3       | Static register
| r27      | s4       | Static register
| r28      | s5       | Static register
| r29      | s6       | Static register
| r30      | s7       | Static register
| r31      | s8       | Static register
|===

[NOTE]
====
Temporary registers are also known as caller-saved registers. +
Static registers are also known as callee-saved registers.
====

.LA32R Control and Status Registers
[cols="1,1,2", options="header"]
|===
| Address | Register  | Description
| 0x0000  | CRMD      | Current Mode Information
| 0x0001  | PRMD      | Previous Mode Information
| 0x0002  | EUEN      | Extension Unit Enable
| 0x0004  | ECFG      | Exception Configuration
| 0x0005  | ESTAT     | Exception Status
| 0x0006  | ERA       | Exception Return Address
| 0x0007  | BADV      | Fault Virtual Address
| 0x000c  | EENTRY    | Exception Entry Address
| 0x0010  | TLBIDX    | TLB Index
| 0x0011  | TLBEHI    | TLB Entry High
| 0x0012  | TLBELO0   | TLB Entry Low 0
| 0x0013  | TLBELO1   | TLB Entry Low 1
| 0x0018  | ASID      | Address Space Identifier
| 0x0019  | PGDL      | Lower Half Address Space Global Directory Base
| 0x001a  | PGDH      | Upper Half Address Space Global Directory Base
| 0x001b  | PGD       | Global Directory Base
| 0x0020  | CPUID     | Processor ID
| 0x0030  | SAVE0     | Data Save Register 0
| 0x0031  | SAVE1     | Data Save Register 1
| 0x0032  | SAVE2     | Data Save Register 2
| 0x0033  | SAVE3     | Data Save Register 3
| 0x0040  | TID       | Timer ID
| 0x0041  | TCFG      | Timer Configuration
| 0x0042  | TVAL      | Timer Value
| 0x0044  | TICLR     | Timer Interrupt Clear
| 0x0060  | LLBCTL    | LLBit Control
| 0x0088  | TLBRENTRY | TLB Refill Exception Entry Address
| 0x0098  | CTAG      | Cache Tag
| 0x0180  | DMW0      | Direct Mapping Configuration Window 0
| 0x0181  | DMW1      | Direct Mapping Configuration Window 1
|===
