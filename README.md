# LoongArch Reference Card
An unofficial reference sheet for LoongArch32 Reduced ISA, inspired by [riscv-card](https://github.com/jameslzhu/riscv-card).

## What's inside?

- The base LoongArch32 Reduced ISA, with opcode values and C-like/ Verilog-like descriptions
- Register aliases and calling conventions
- Pseudoinstructions
