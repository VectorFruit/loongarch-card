.LA32R Privilege Instruction Formats Table
[cols="2,1,2,2,3", compact, options="header"]
|===
| Inst             | FMT   | Opcode               | NOTE                            | Description
| CSRRD rd, csr    | 2RI14 | `00000100`           | `I14 = CSR, rj = 0b00000`       | `GR[rd] = CSR[csr]`
| CSRWR rd, csr    | 2RI14 | `00000100`           | `I14 = CSR, rj = 0b00001`       | swap `GR[rd]` and `CSR[csr]`
| CSRXCHG rd, rj, csr  | 2RI14 | `00000100`           | `I14 = CSR, rj != 0, 1`         | swap `GR[rd]` and `CSR[csr]`, `GR[rj]` used as CSR wmask
| CACOP code, rj, si12    | 2RI14 | `000001 1000`        | `I14[14:13]` as opcode          | 
| TLBSRCH   | 2R    | `000001 1001 00 10000 01010` | `rd, rk = 0b00000`       | 
| TLBRD     | 2R    | `000001 1001 00 10000 01011` | `rd, rk = 0b00000`       | 
| TLBWR     | 2R    | `000001 1001 00 10000 01100` | `rd, rk = 0b00000`       | 
| TLBFILL   | 2R    | `000001 1001 00 10000 01101` | `rd, rk = 0b00000`       |
| ETRN      | 2R     | `000001 1001 00 10000 01110` | `rd, rk = 0b00000`       |
| IDLE level         | 3R    | `000001 1001 00 10001`       | `level = inst[14:0]`     |
| INVTLB op, rj, rk  | 3R    | `000001 1001 00 10011`       | `op = inst[4:0]`                         | 
|===

NOTE: La32r Privilege architecture has two privilege levels: PLV0 and PLV3. For Linux, PLV0 refers to the kernel mode, while PLV3 refers to the user mode. The PLV is stored in the `PLV` field of the `CSR.CRMD` register.
